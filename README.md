## المنظومة الذاتية المتقدمة لفحص أمان الوكلاء، تدقيق الشفرات، ومطابقة الهوية المهنية

**نظام ذكي متكامل ومستقل لفحص الأكواد البرمجية، اكتشاف ثغرات الوكلاء والمساعدين (AI Agents)، وتدقيق مطابقة المخرجات مع معايير الأمان والهوية المهنية — بدقة عسكرية وموارد مجانية 100%.**

يُمسح أي مستودع أو مجلد مهارات (Skills) بحثاً عن الثغرات الخفية: تسريب مفاتيح، حقن SQL/OS/XSS، أوامر محقونة داخل مهارات الوكلاء، روابط تنفيذ مخفيّة — ثم يحوّل الذكاء الاصطناعي كل تقرير خام إلى **شرح مبسّط + كود إصلاح جاهز**، ويحفظه في سجلّ دائم، ويُنبّهك على تليفونك فوراً.

> 💰 **تكلفة صفر** — لا اشتراك في أي منصة فحص أمني مدفوعة.

## 📋 لماذا يتمنّى كل مطوّر وكل شركة الحصول عليه؟

| الميزة | القيمة |
|---|---|
| 💰 **توفير مال فلكي** | أدوات التدقيق الأمني المتقدمة تُفوّت على الشركات مبالغ باهظة شهرياً — هنا نفس القدرة بتكلفة صفر. |
| 🛡️ **صِفر تسامح مع الثغرات** | يكتشف الثغرة قبل نشرها، لا بعده. |
| 🔒 **سيادة وخصوصية تامة** | الفحص يجري داخل بيئتك: لا سطر كود يخرج لجهة خارجية إلا إن فعّلت أنت خدمة الذكاء الاصطناعي. |
| 🤖 **وُلد لأجل الوكلاء** | المهارات (SKILL.md) والوكلاء أنفسهم تحت الفحص: تعليمات محقونة، أوامر تنفيذ خبيثة، تسريب سياق. |

## 🛠️ الموارد المجانية البحتة (The Free Tech Stack)

| المكوّن | التقنية المجانية | الدور |
|---|---|---|
| محرك التشغيل المجدول (CI/CD) | **GitHub Actions** | تنفيذ التدقيق مع كل Push/PR/جدولة أسبوعية |
| محرك الفحص الساكن | **Python (محرّك قواعد مدمج)** + Semgrep OSS / Bandit / Trivy | كشف الثغرات والأنماط الخطرة (المحرك المدمج يعمل بلا أي تثبيت) |
| عقل التدقيق الذكي | **Google Gemini API / Groq API / OpenRouter** (Free Tiers) | تفسير الثغرة + توليد كود الإصلاح الآمن |
| سجلّ التدقيق | **Supabase (PostgreSQL Free Tier)** | أرشيف الفحوصات وتتبّع مستوى الأمان عبر الزمن |
| التنبيه الفوري | **Telegram Bot API** | إرسال تنبيه عاجل بالثغرة والحل |

## 📐 البنية البرمجية (4 طبقات)

```
[مستودعك / مجلد مهارات الوكيل]
              │  push · PR · cron
              ▼
[GitHub Actions ──► static_scan: قواعد مدمجة + Semgrep/Bandit/Trivy]
              │
              ▼
[AI Audit Core ── Gemini / Groq ── تفسير + كود إصلاح آمن]
              │
              ▼
[Supabase (سجلّ دائم)  ──►  Telegram (تنبيه فوري)]
```

1. **طبقة الفحص الساكن** — `audit/rules.py` قواعد مدمجة (تعمل بلا إنترنت) + تغليف اختياري لـ Semgrep/Bandit/Trivy.
2. **عقل التدقيق** — `audit/ai_audit.py` يقرأ النتائج الخام ويُنتج: الخطورة، السبب، الإصلاح، وكوداً آمناً جاهزاً للاستبدال.
3. **طبقة الأرشيف** — `audit/store.py` يكتب إلى Supabase REST (مُعطَّل تلقائياً إن لم ضبط المتغيّرات).
4. **طبقة التنبيه** — `audit/notify.py` يرسل تقريراً مريحاً للعين إلى تليجرام.

## ⚡ التشغيل السريع

```bash
# 1) فحص فوري — بدون أي تثبيت (محرّك مدمج بالكامل)
python -m audit scan .

# 2) تقرير JSON + كسر البناء إن وُجدت ثغرة حرجة/عالية
python -m audit scan . --format json --out report.json --fail-on high

# 3) إضافة التدقيق الذكي (اختياري)
cp .env.example .env      # ثم ضع مفاتيحك داخل .env
python -m audit scan . --ai
```

### المتغيّرات (كلها اختيارية — الفيعمل بدونها)

| المتغيّر | الوظيفة |
|---|---|
| `GEMINI_API_KEY` أو `GROQ_API_KEY` أو `OPENROUTER_API_KEY` | تفعيل عقل التدقيق الذكي |
| `SUPABASE_URL` + `SUPABASE_SERVICE_KEY` | حفظ سجلّ التدقيق |
| `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` | تنبيهات فورية |

### في GitHub Actions

ارفع الكود إلى مستودعك ثم أضف الأسرار من:
`Settings → Secrets and variables → Actions`

- `GEMINI_API_KEY` (أو `GROQ_API_KEY`)
- `SUPABASE_URL` / `SUPABASE_SERVICE_KEY`
- `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID`

ملف التدقيق: `.github/workflows/audit.yml` (يُشغَّل مع كل push وPR + جدول أسبوعي).

## 🤖 ما الذي يفحصه خصيصاً لمهارات الوكلاء؟ (Audit-Skill)

- تعليمات محقونة: «تجاهل القواعد السابقة» / «لا تذكر هذا لل المستخدم».
- أوامر تنفيذ مخفية: `curl … | bash`، `Invoke-Expression`، `base64 -d | sh`. <!-- audit:ignore -->
- تسريب سياق: رفع ملفات `.env` أو `.git` أو مخرجات `env` إلى أي وجهة.
- روابط مشبوهة وكيانات خارجية تُحمَّل أثناء تنفيذ المهارة.
- مطابقة الهوية المهنية: وجود `LICENSE`، ذكر المؤلف، بيانات دعم صحيحة، وخلو المستودع من مفاتيح.

```bash
python -m audit scan path/to/skills --profile skills
python -m audit scan . --profile identity   # تدقيق الهوية والملكية فقط
```

## 🤫 كتم الإنذار الكاذب (False-Positive Muting)

قد يستهدف الفحص عناصر مقصودة داخل ملفات المشروع نفسه (نصوص توثيقية، أنماط قواعد). آلية الكتم المدمجة:

1. **علامة على السطر** — أضف `audit:ignore` في نهاية أي سطر تعرف أنه آمن، فيُتخطّى الفحص له:

   ```python
   pattern = r"(curl|wget).*\|\s*sh"  # audit:ignore
   ```

2. **تجاهل ملفات النواتج** — الملفات التالية تُستبعد تلقائياً من الفحص: `audit-report.*`، `self-report.*`، `report.json/md`، `*.min.js`، `*.map`، `*.lock`.

3. **استثناء المجلدات** — المجلدات المكرّرة مثل `.git`، `node_modules`، `dist`، `.venv` تُتخطّى دائماً (قابلة للتعديل في `audit/static_scan.py`).

> ✅ هذا المشروع يُفحص نفسه عند كل إصدار: `verdict=clean` شرط النشر.
